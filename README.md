نظام برمجي متكامل ومتقدم لإدارة العقارات، الوحدات، العقود، المستأجرين، التحصيلات المالية، المحاسبة المزدوجة المتوازنة، تذاكر الصيانة، وبوابات الخدمة الذاتية، مدعوماً بمستشار الذكاء الاصطناعي العقاري وتحليلات المحاكاة الاستثمارية.

---

## 🌟 الميزات الرئيسية للنظام (Core Modules)

### 1. إدارة العقارات والوحدات (Properties & Units)
- بطاقات العقارات، نسب الإشغال اللحظية، وتفاصيل المباني.
- إدارة الوحدات (سكنية، تجارية، مكاتب، مستودعات) مع تحديد الأسعار والخدمات.
- ربط الوحدات بالعقارات والملاك وإدارة حالاتها (شاغرة، مؤجرة، تحت الصيانة).

### 2. العقود والتحصيلات والمالية (Contracts & Rent Collection)
- إنشاء وإدارة عقود الإيجار (سنوي، نصف سنوي، ربع سنوي، شهري).
- توليد أوتوماتيكي لجدولة الدفعات (Rent Schedules) وتتبع الأقساط المستحقة والمتأخرة.
- تسجيل المدفوعات وتوزيع السداد التلقائي (FIFO) وسندات القبض المطبوعة برقم مرجعي فريد.

### 3. القيود المحاسبية وتسويات الملاك (Double-Entry Accounting)
- شجرة حسابات متكاملة (أصول، خصوم، إيرادات، مصروفات).
- قيود يومية مزدوجة مع تطبيق فحص التوازن الصارم (`Debit === Credit`).
- تسجيل المصروفات التشغيلية والرأسمالية وربطها بالعقارات والوحدات والموردين.
- تسويات الملاك المالية الآلية وحساب صافي الدخل وحصص الملاك بدقة.

### 4. إدارة الصيانة والتشغيل (Maintenance & Work Orders)
- تذاكر صيانة تفاعلية مع تصنيف الأولويات (عاجل جداً، مرتفع، متوسط، منخفض).
- تحويل التذاكر إلى أوامر عمل وإسنادها للفنيين والموردين وتتبع التكاليف.
- خطط صيانة وقائية دورية ومجدولة لحماية الأصول العقارية.

### 5. البوابات المخصصة للخدمة الذاتية (Self-Service Portals)
- **بوابة المستأجر (`/portal/tenant`)**: الاطلاع على العقد، جدول الدفعات القادمة، وسداد الإيجار، ورفع ومتابعة طلبات الصيانة.
- **بوابة المالك (`/portal/owner`)**: تقارير الأداء المالي، نسبة إشغال العقارات، ومتابعة التحويلات المالية والتسويات الدورية.

### 6. مستشار الذكاء الاصطناعي ومحاكي الاستثمار (`/ai-advisor`)
- استشارات استثمارية وتحليلات تنبؤية قائمة على بيانات النظام الحقيقية.
- محاكي اتخاذ القرارات: محاكاة تغيير أسعار الإيجار ونسب الإشغال ورؤية العائد المتوقع لحظياً.

### 7. الأمان والصلاحيات وسجل التدقيق (RBAC & Audit Trail)
- نظام صلاحيات صارم على مستوى الخادم (Server-Side Enforcement).
- 7 أدوار رئيسية و 38 صلاحية برمجية مفصلة.
- سجل تدقيق إلكتروني غير قابل للتعديل (Immutable Audit Log) لتوثيق جميع العمليات الحرجة.

## 🚀 التشغيل السريع (Quickstart)

### 1. المتطلبات (Prerequisites)
- [Node.js 18+](https://nodejs.org/)

### 2. تثبيت الحزم (Installation)
```bash
npm install
```

### 3. إعداد قاعدة البيانات والبيانات الأولية (Database Setup)
النظام مهيأ تلقائياً للعمل بقاعدة بيانات SQLite محلية لا تحتاج لأي إعداد خارجي:
```bash
# توليد عميل Prisma
npx prisma generate

# تحديث هيكل قاعدة البيانات
npx prisma db push

# تغذية قاعدة البيانات بالبيانات النموذجية والأدوار
npx prisma db seed
```

### 4. تشغيل خادم التطوير (Start Dev Server)
```bash
npm run dev
```
افتح المتصفح على: **`http://localhost:3000`**

## 🧪 الاختبارات الآلية والتحقق (Automated Tests)

النظام مزود بحزم اختبارات آلية شاملة لاختبار الأمان وقواعد الأعمال وتوازن القيود:

```bash
# تشغيل جميع اختبارات Vitest (19 اختبار ناجح)
npm test

# تشغيل فحص شامل لجميع واجهات API ومسارات الشاشات الـ 14
node scripts/verify-api.mjs
```

### ملخص نتائج الفحص:
- **`tests/rbac.test.ts`**: فحص حماية المسارات وصلاحيات الأدوار الـ 7.
- **`tests/database.test.ts`**: التحقق من سلامة العلاقات وقاعدة البيانات.
- **`tests/operations.test.ts`**: فحص توزيع الدفعات (FIFO) وتوازن القيود المحاسبية (`Debit === Credit`).
- **`tests/auth.test.ts`**: فحص تشفير Bcrypt وتوليد وفك توكنات JWT الآمنة.

## 🐳 النشر على بيئة الإنتاج مع PostgreSQL (Production Deployment)

يتوفر في المشروع ملف إعداد PostgreSQL كامل جاهز للعمل مع Docker:

1. شغل الحاوية عبر Docker Compose:
```bash
docker-compose up -d
```
2. انقل ملف الـ schema إلى PostgreSQL:
```bash
cp prisma/schema.postgresql.prisma prisma/schema.prisma
npx prisma db push
npx prisma db seed
```
3. قم ببناء المشروع وتشغيله:
```bash
npm run build
npm start
```
